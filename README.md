# Did You Get the Level You Asked For? · AIIDE 2026

Interactive slides for the AIIDE 2026 poster
*Bridging LLMs and PCGRL for Super Mario Bros. Level Generation*
(Bruno Lemos, Luiz Chaimowicz · UFMG).

- **Slides / demo:** https://brunolemosdl.github.io/intent-pcgrl-aiide26/
- **Poster (PDF, 90 × 120 cm):** [poster.pdf](poster.pdf) · static slides: [slides.pdf](slides.pdf)
- **Code, models and data:** https://github.com/brunolemosdl/intent-pcgrl

Keys: → / space next, ← back, **N** speaker notes + 5:00 timer, **F** fullscreen. Link to a slide with `#4`.

Every level shown was generated by the released 10M-step policy and completed by the
Mario AI Framework A* agent; all chart values come from the paper.
